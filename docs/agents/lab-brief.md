# Lab brief: SDLC Lab 0

This repo is a submission for SDLC Lab 0 in DAV 6300 "Agentic Coding" (Yeshiva University). **Andy** is Prof. Andy Catlin, the instructor; "per Andy" means per this brief. The source is his handout `Pocock-SDLC-Lab0-Student-Instructions.docx` (emailed 2026-10-05), which is not in the repo.

## Deliverables

The lab is done when every row holds:

| # | Deliverable | Check |
|---|---|---|
| 1 | Repo created from the template `acatlin/pocock-end-to-end-js`: public, not a fork, Issues on | `gh repo view --json visibility,isFork,hasIssuesEnabled,templateRepository` |
| 2 | GitHub Pages on, source GitHub Actions, site live | latest `Publish site` run on `main` green; https://ubuyfirst.github.io/pocock-lab/ loads |
| 3 | Skills pointed at this repo's GitHub Issues | `docs/agents/issue-tracker.md` exists; `gh issue create` works |
| 4 | `FEATURE.md` holds one sentence for one page or chart, with no "and" | `cat FEATURE.md` |
| 5 | The feature built through `/grill-with-docs` -> `/to-spec` -> `/to-tickets` -> `/implement` -> `/code-review` -> PR -> merge | a spec issue, ticket issues, a merged PR, the feature on the live site |
| 6 | Self-check posted to Andy: the live URL and the feature sentence | sent by the student, outside the repo |
| 7 | GitHub profile README and LinkedIn link to the live site | `ubuyfirst/ubuyfirst` README links the Pages URL; LinkedIn is the student's |

Rows 6 and 7 are outward-facing: draft them, and the student sends or publishes.

## Grading frame

From the course description: professional conduct, shipped product, customer outcomes. Process counts, so work beyond `FEATURE.md` still goes through the skills, not hand-written specs.
